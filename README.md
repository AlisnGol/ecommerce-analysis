# Анализ заказов интернет-магазина Olist

Исследовательский анализ данных бразильского маркетплейса Olist: динамика продаж, повторные покупки, влияние доставки на отзывы, категории товаров и способы оплаты.

📓 **Весь анализ с кодом и графиками:** [analysis.ipynb](analysis.ipynb)

## Данные

[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) — ~100 тыс. заказов за 2016–2018 годы, 9 связанных таблиц (заказы, покупатели, товары, оплаты, отзывы и др.).

Данные не хранятся в репозитории — их нужно скачать с Kaggle и положить в папку `data/`.

## Стек

Python, pandas, matplotlib, Jupyter Notebook

## Подготовка данных

- Даты переведены из текста в формат datetime.
- Проверено качество данных: пропуски в дате доставки почти полностью объясняются недоставленными заказами. Найдено 14 аномалий (доставленные заказы без даты и наоборот, 0,01% данных) — исключены из анализа доставки.
- Для анализа динамики взяты только полные месяцы (январь 2017 — август 2018).

## Ключевые выводы

**1. Динамика заказов и выручки.** В 2017 году число заказов выросло с ~800 до ~4 500 в месяц. В ноябре 2017 — пик (~7 400 заказов), вероятно из-за Чёрной пятницы. В 2018 году рост остановился: плато ~6–7 тыс. заказов и ~1–1,15 млн R\$ в месяц.

**2. Повторные покупки.** Повторно купили только **3%** покупателей. Рост держится почти полностью на новых клиентах — есть потенциал в программах удержания.

**3. Доставка и отзывы.** Опаздывает 6,8% заказов. Средняя оценка: **4,29** при доставке вовремя и **2,27** при опоздании. Больше половины опоздавших заказов получают оценку 1 (против 7% у доставленных вовремя). Задержка доставки — один из главных источников негативных отзывов.

**4. Категории.** Лидеры по выручке — health_beauty, watches_gifts и bed_bath_table. Они зарабатывают по-разному: bed_bath_table — за счёт объёма продаж, watches_gifts — за счёт высокой средней цены (~201 R\$).

**5. Оплата и чек.** 74% платежей — кредитной картой, 19% — boleto (бразильская платёжная квитанция). Средний чек — 160 R\$, медианный — 105 R\$: среднее завышено небольшим числом дорогих заказов.
